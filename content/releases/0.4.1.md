## How to upgrade

Open Updates in the console, or run `crust molt update`. VMs keep running; apps restart one at a time; the node reboots into the new image. If health checks fail, Molt rolls back to 0.4.0 by itself.

## Upgrade notes

- No config changes needed.
- Nodes in a Cast cluster upgrade one at a time.
- From 0.3.x, upgrade to 0.4.0 first.
